      A focused toolkit for real document work.

      PDF Tools is built for practical jobs that appear in school, work, business, and personal administration: joining documents for an application, extracting a few pages from a report, reducing the size of a scanned file, turning phone photos into a clean document, recovering text for notes, or correcting pages scanned sideways. Rather than hiding those tasks behind an account wall or a complicated desktop application, this site keeps the workflow direct. Choose a tool, select a file, make the necessary choice, and download the result.

      The defining principle is local processing. The page uses JavaScript PDF libraries inside your browser, so selected document bytes are handled on your device instead of being intentionally sent to a document-processing server. That approach is useful when a file contains schoolwork, invoices, forms, drafts, or other material you would rather not upload merely to perform a basic edit. Processing speed depends on your device, browser, page count, and source complexity. Large image-heavy PDFs may use substantial memory, particularly during compression.

      Each tool has one clear outcome. Merge preserves selection order. Split accepts individual pages and ranges. Rotate can change every page or only the pages you identify. Images to PDF supports common browser image formats and offers image-sized, A4, and US Letter layouts. PDF to Text reads the text layer already present in a document; it does not perform optical character recognition on photographed or scanned text. Compression rebuilds pages as balanced-quality images, which may reduce scanned documents significantly but also flattens selectable text and interactive elements.

      The site requires no registration and works across modern desktop and mobile browsers. Results are generated for immediate download, and temporary selections disappear when the tab is refreshed or closed. Because PDF files vary widely, open the downloaded result and check page order, orientation, readability, links, forms, and signatures before replacing an original. Keep a backup of important source documents. PDF Tools is a convenient utility, not a substitute for archival, legal, accessibility, or professional prepress software.

      Questions, answered.

      Are my files uploaded?

      The document tools process selected files in your browser. The page does not intentionally upload their contents to a document-processing server. Third-party advertising resources load separately.

      Why did compression remove selectable text?

      Compression rebuilds pages as images to reduce scanned or image-heavy files. This flattens text, links, forms, and annotations.

      Can PDF to Text read scanned pages?

      Only when the PDF already contains a text layer. A photo or scan without embedded text needs OCR, which is not included.

      Can I open password-protected PDFs?

      Encrypted files may not open. Remove protection with the authorized password in trusted software first.

      Is there a file-size limit?

      Your browser and device memory set the practical limit. Very large PDFs may fail on memory-constrained phones.

      What should I verify afterward?

      Check page order, orientation, quality, text, forms, links, and signatures. Keep the original when a document matters.
